# Flibusta Reader для Android

Flibusta Reader — современный, быстрый, легкий и удобный клиент для каталога онлайн-библиотеки Флибуста под операционную систему Android.

Приложение спроектировано для комфортного чтения, поиска и скачивания книг. В интерфейсе отсутствуют визуальный шум и реклама, все интерактивные элементы понятны, а навигация логична и интуитивна.

---

## Основные возможности

### 1. Каталог и Рекомендации
* Отображение книги дня с обложкой, аннотацией и быстрым добавлением на полку.
* Горизонтальная карусель популярных книжных серий и циклов.
* Лента рекомендованных книг с фильтрацией по жанрам (Фэнтези, Фантастика, Попаданцы, Детективы, ЛитРПГ, Приключения, Боевики).
* Быстрые действия: случайная книга, новинки недели, настраиваемая сортировка.

### 2. Умный поиск с постраничной загрузкой
* Три независимых режима поиска:
  * Поиск по книгам;
  * Поиск по книжным сериям и циклам;
  * Поиск по авторам.
* Поддержка непрерывной подгрузки результатов при прокрутке списка (пагинация).
* Сортировка результатов поиска по названию, автору, дате или номеру в серии.

### 3. Фоновая пакетная загрузка целых серий
* Возможность в один клик скачать все книги выбранного цикла или серии.
* Загрузка выполняется в системном Foreground Service с уведомлением в шторке Android и индикацией прогресса.
* Автоматическая привязка порядкового номера книги в серии.

### 4. Моя библиотека и офлайн-полка
* Разделы библиотеки:
  * Все книги на полке;
  * По сериям (группировка скачанных циклов);
  * По авторам (группировка скачанных книг по авторам с счетчиком произведений);
  * Скачано (только файлы, сохраненные в память устройства);
  * Читаю, Прочитано, В планах.
* Информационная панель памяти: отображение общего количества сохраненных книг и объема занимаемого места (в КБ или МБ).
* Удаление локального файла книги с сохранением записи на полке при необходимости.
* Офлайн-режим: при отсутствии интернета приложение мгновенно переключается на локальную базу данных, открывая доступ ко всем скачанным книгам, сериям и авторам.

### 5. Резервное копирование и восстановление (Бэкап)
* Экспорт всей базы библиотеки в структурированный JSON-файл в папку Downloads/Flibusta/.
* Восстановление библиотеки из резервной копии с автоматической защитой от дубликатов.

### 6. Отправка книг и файлов
* Встроенная интеграция с Android FileProvider.
* Если книга скачана, кнопка «Поделиться» отправляет непосредственно файл книги (.fb2, .epub, .mobi, .pdf) в Telegram или другие приложения.
* Если книга еще не скачана, генерируется текстовая ссылка с описанием для быстрой отправки друзьям.

### 7. Эргономичный и лаконичный интерфейс
* Чистый дизайн без лишних отвлекающих элементов.
* Удобное жестовое и кнопочное управление, продуманные размеры элементов касания.
* Быстрый отклик и плавная прокрутка больших списков.

### 8. Встроенная система автообновлений через GitHub Releases
* Автоматическая проверка официальных релизов напрямую с GitHub при старте приложения.
* Скачивание актуального APK из релизов GitHub внутри приложения с индикатором загрузки и вызовом установщика пакетов Android.

## Архитектура и технологии

* Язык: Java 17
* Минимальная версия Android: Android 5.0 (API level 21)
* Целевая версия Android: Android 14 (API level 34)
* Сеть: Нативные HttpURLConnection-клиенты с поддержкой OPDS (Open Publication Distribution System) XML-каталогов и парсинга HTML.
* База данных: Встроенная SQLite с DatabaseHelper.
* UI: Material Components, CardView, RecyclerView, BottomNavigationView.
* Загрузка обложек: Оптимизированный асинхронный ImageLoader с дисковым и оперативным кэшированием.

## Сборка и установка

### Готовый APK:
Свежий релиз приложения всегда доступен в разделе Releases репозитория:
https://github.com/Ivankolp/flibusta-android/releases

Прямая ссылка на последний релиз с GitHub:
https://github.com/Ivankolp/flibusta-android/releases/latest/download/Flibusta.apk

### Сборка из исходников:

Требуется установленный JDK 17 и Android SDK.

```bash
git clone https://github.com/Ivankolp/flibusta-android.git
cd flibusta-android
./gradlew assembleDebug
```

Скомпилированный файл APK появится по пути:
`build/outputs/apk/debug/app-debug.apk`
